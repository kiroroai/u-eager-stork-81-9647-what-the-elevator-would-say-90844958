Entry for the [make.fun](https://make.fun) competition
["What the Elevator Would Say"](https://make.fun/c/u-eager-stork-81-9647-what-the-elevator-would-say-90844958):
the funniest one line a talking elevator could say, in the elevator's own voice.

## The line

> Ding! Floor 12. Relax — I never saw you leave at 3 a.m. with someone else's pizza.

## How it works

`main.py` writes that single line (82 characters, one line, no trailing
newline issues) to `/output/entry.txt`. It is fully deterministic: fixed
text, no randomness, no clock, no network.

```sh
python3 main.py
cat /output/entry.txt
```
